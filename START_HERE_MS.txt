NEW WORLD DIGITAL — PANDUAN MULA

1. Ekstrak ZIP.
2. Muat naik index.html, app.js, style.css, README.md, START_HERE_MS.txt dan .nojekyll ke root repository GitHub (gantikan fail versi lama).
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Buka URL GitHub Pages.
5. Daftar akaun. Akaun mungkin perlu kelulusan Master Admin sebelum boleh masuk.
6. Bergerak dengan WASD / anak panah. Di telefon, gunakan butang arah di bawah peta.
7. Berjumpa pemain lain dan gunakan Sembang Dunia untuk berbual.

PERINGATAN: Backend Supabase dan fungsi permainan asas telah dipasang. Sebelum pelancaran umum, ujian dua akaun serentak masih perlu dibuat. Jangan masukkan service_role key ke frontend.

KESELAMATAN MASTER:
- Fail GitHub tidak mengandungi kata laluan Master.
- Selepas log masuk sebagai Master, buka panel MASTER CONTROL dan gunakan borang TUKAR KATA LALUAN MASTER.
- Masukkan kata laluan baharu dan pengesahan terus pada laman permainan. Jangan tulis kata laluan dalam kod atau README.
- Kunci sb_publishable dalam app.js ialah kunci awam Supabase untuk browser; jangan masukkan service_role/secret key.
