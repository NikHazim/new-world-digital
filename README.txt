TANAH AIR KU — LIFE SIMULATOR

Cara main:
1. Buka index.html melalui hosting web (GitHub Pages disyorkan).
2. Internet diperlukan untuk memuatkan Three.js dan Supabase JS.
3. Tekan MASUK KE DUNIA. Akaun online adalah pilihan; boleh bermain tanpa log masuk.
4. Android: joystick kiri untuk bergerak, seret ruang kanan untuk pusing kamera, AKSI untuk berinteraksi.
5. PC: WASD/anak panah untuk bergerak, seret ruang permainan untuk pusing kamera.

Ciri yang berfungsi dalam build ini:
- Dunia 3D orang ketiga dengan pekan, bangunan, pokok, jalan dan kereta.
- Kawalan sentuh dan papan kekunci.
- Interaksi: kerja, kedai, kafe, rumah, ladang, tasik, pasar, bengkel dan balai komuniti.
- Wallet permainan tempatan, inventori, tenaga, hari, misi, memancing, jual beli asas.
- Simpanan automatik localStorage pada peranti.
- Supabase Auth (daftar/log masuk) dan bacaan profil wallet online.

Had yang diketahui:
- Ganjaran dan pembelian permainan ketika ini disimpan secara lokal; belum diselaraskan ke wallet online kerana operasi ekonomi server-side belum dibina.
- Tiada multiplayer masa nyata, chat, NPC pintar atau sistem trafik penuh dalam build ini.
- Peta dan dunia ialah satu kawasan awal, bukan dunia berskala besar.
- Pastikan domain GitHub Pages ditambah dalam Supabase Auth URL Configuration dan tetapan pengesahan e-mel disemak sebelum pelancaran umum.
