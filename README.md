# NH TRADE EMPIRE — Your World, Your Story

A small, browser-playable cozy life-sim prototype inspired by social world games and farming sims. Original NH Trade Empire branding and original code.

## Play locally
Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html` (and this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Open the published Pages URL.

## Controls
- Desktop: WASD or arrow keys to move; Space or E to interact. Use PROFILE to set your player name, change outfit/hair/skin, and view level/XP/coins. Tap FULL SCREEN for immersive view.
- Mobile: on-screen directional pad and ACTION button.
- Walk near a character or building and interact.
- NH Market: buy seeds / sell harvested crops.
- NH Farm: plant and harvest.
- Empire Home: sleep to advance the day and grow crops.

## Prototype notes
The world map is expanded to 70 × 55 tiles. Player profile settings are stored in the browser on that device. Mobile text-selection is disabled on game controls, and a fullscreen button is included. This is a single-player HTML Canvas prototype. Art is drawn procedurally in the browser, so no external assets or install steps are required. It is not a full Sims/Habbo/Harvest Moon-scale game yet; multiplayer, persistent save files, character customization, and expanded quests are future features.
