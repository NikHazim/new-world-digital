# NHDC Digital World — Playable Game v1.0

A mobile-responsive, standalone browser game for Nik Hazim Digital World. No build step or package installation is required.

## Play it
- Open `index.html` in a modern browser, or upload the entire folder to static website hosting.
- On a website, open the deployed `index.html` page.

## Included and playable
- Three mini-games: NH Catch (30-second reflex challenge), Memory Galaxy (matching puzzle), Treasure Hunt (hidden treasure grid).
- Player profile and local save.
- XP, levels, daily login streak and daily claim.
- Daily missions and claimable rewards.
- Cosmetic avatar shop and inventory.
- Activity history, personal bests, save export/import, reset.
- Mobile-responsive interface.
- In-game NHDC balance with a 21,000,000 per-local-save ceiling and scheduled annual reward halving.

## Important scope
This is a playable single-device release. Player profiles, balance, missions and rankings are stored in the browser's localStorage. The 21,000,000 ceiling is enforced per local save, not globally across all players. Global accounts, cross-device sync, a verified global 21-million issuance cap, anti-cheat and a worldwide leaderboard require a shared backend/database and server-side validation. This release has no blockchain, cash value, cash-out or real-money transaction.
